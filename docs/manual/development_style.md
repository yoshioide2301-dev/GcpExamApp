# 開発スタイル・マニュアル

このドキュメントは、本プロジェクトにおける開発フロー・セキュリティ方針・コスト方針の正式な定義です。
Claude Code はセッション開始時にこの内容を前提として作業すること。

最終更新: 2026-09-19

## 🔄 開発の上昇サイクル（4つのステップ）

1. **① 二刀流による超高密度プロンプト生成**
   GeminiまたはChatGPTで問題データやUI仕様を100%練り上げ、無駄のない1発の指示としてClaude Codeに投入する。イン（入力）トークンを極限まで節約し、月額サブスクの枠内で最大の開発効率を叩き出す。フロントのAI（Gemini/ChatGPT）は状況に応じて柔軟に使い分ける。

2. **② AI資産の蓄積と可搬性の維持（いつでも移行できる状態の担保）**
   修正完了時に、Claudeが自律的に `docs/manual/` へ技術履歴サマリーをMarkdown形式で自動蓄積する。これにより、将来的にCodex等の他ツールへ移行する必要が出た場合でも、1秒で文脈を完全引き継ぎできるポータビリティ（可搬性）を常にキープする。

3. **③ クラウド本尊（GitHub Pages）への即時同期**
   ローカルPCの電源状態に依存せず、24時間365日いつでもiPhoneから世界共通URLで検証できる環境に自動push・自動デプロイする。

4. **④ スマホ実機からの逆算フィードバック（App Storeリリースへの最短ルート）**
   PWA全画面モードで触った気づきから、ライバルアプリ（ウェザップ等）を凌駕する「クール・シンプル・直感的なUI」へブラッシュアップし、最速でのApp Store無料リリースへ繋げる。

## 🔒 セキュリティ＆コスト厳守ルール

- **DO NOT hardcode or read any personal data, user credentials, or client information.**
  （個人情報や機密データをコード内に直接記述・読込しないこと）
- **Keep code changes minimal and concise to maintain cost efficiency.**
  （コストとトークン節約のため、コード変更は常に最小限かつ簡潔に行い、不要な外部ライブラリを勝手に追加しないこと）
